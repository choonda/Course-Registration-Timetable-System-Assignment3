# Course-Registration-Timetable-System
SCSE2103 DATA STRUCTURES &amp; ALGORITHMS Mini Project

The purpose of this project is to provide an efficient, organized and user-friendly platform for managing course registration and timetable information. It aims to streamline the process of viewing available courses, search for specific course details and maintain accurate scheduling for both administrators and students.

This system focuses on core functions related to course registration and timetable management using array-based data structures. Its scope includes loading course data from files, displaying course lists, searching and sorting course records, allowing students to register for courses and enabling administrators to manage course offerings. This system also provides menu interactions for multiple user which is student and admin, ensuring proper navigation and functionality

Admin Module
- Course Management: Add, update, or remove courses from the master list.

- Timetable Management: Organize schedules using Selection, Bubble, and Insertion Sort.

- Registration Approval: Process student enrollment requests using a FIFO (First-In, First-Out) Queue.

- Data Persistence: Automatically saves and loads data from .txt files.

Student Module
- Course Search: Find courses by code or name using Linear Search.

- Enrollment: Apply for courses by entering an administrative waiting list.

- Personal Timetable: View and sort approved courses by lecturer, code, or credit hours.

- Drop Course: Manage personal workload by removing registered courses.
